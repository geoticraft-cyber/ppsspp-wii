# ppsspp-wii
an ai assisted project that aims tobbe the first psp emulator for the wii, assisted by ppsspp source and chatgpt 6.1 sol. credits to PPSSPP developers/contributors for the groundwork, ai for most of the code, and nastypenguin101/geoticraft as the lead developer.

Games Currently tested + working: Terraria PSP by XD: roughly 3.0fps at stock settings, slight graphical issue: on startup, the text are pink for some reason. GTA VCS: roughly 1.0fps but far slower speed observed in real time gameplay, no graphical issues. LBP: fps/speed forgot, runs but is extremely slow tho faster than VCS. no graphical issues, movie plays goodly. GOW ghost of sparta: reaches PAL/EU version's language menu. i got bored because it was too slow so i shut down my wii, therefore its unknown if it can reach gameplay or not.
