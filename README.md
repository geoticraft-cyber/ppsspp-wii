# PPSSPP4Wii
an ai assisted project, that probably is the first psp emulator for the wii, assisted by ppsspp for the HLE and groundwork and chatgpt 6.1 sol for most of the coding. first version way made in october 18 2026, and optimized/changed afterwards. credits to PPSSPP developers/contributors for the groundwork, ai for most of the code, and geoticraft-cyber as the lead developer.

Games Currently tested + working: Terraria PSP by XD: roughly 3.0fps at stock settings, slight graphical issue: on startup, text such as singleplayer and exit which are supposed to be yellow, are pink for some reason. GTA VCS: roughly 1.0fps but far slower speed observed in real time gameplay, no graphical issues. LBP: fps/speed forgot, runs but is extremely slow tho faster than VCS by a mile. no graphical issues, takes roughly 68 minutes to get in game. GOW ghost of sparta PAL: reaches language menu. graphical glitches at start, but they go away, probably because the wii is too laggy. i got bored because it was too slow, therefore its unknown if it can reach gameplay or not.
it uses an intepreter, and mostly software video emulation. but, there is GX Acceleration avaiable. (unrestricted reuse of this text allowed, under license GPL 2.0)
